
# 👥 Team Management Service — Flowsales

Gerencia equipes, permissões, convites, papéis e auditoria de atividades.

## 🚀 Tecnologias

- Node.js / TypeScript
- PostgreSQL + Redis
- JWT, Rate Limiter
- Observabilidade (Prometheus, Grafana, OpenTelemetry)
- Docker, Helm, CI/CD

## 🛠️ Comandos

- `make dev` - roda localmente
- `make test` - executa testes
- `make lint` - valida estilo
- `make build` - cria a imagem Docker

## 🔐 Segurança

- JWT assinado
- Rate limiter e CORS
- `.env.example` para variáveis

## 📈 Observabilidade

- Métricas em /metrics
- Integração com Grafana e Prometheus
